NOTE NINZA

Source Code

This project is a real-time speech-to-text translator and summarizer that converts spoken language from various sources (microphone, audio files, or system sound) into transcribed text in multiple languages. It utilizes Whisper (an advanced speech recognition model) for transcription and BART (a transformer-based model) for summarization. The goal is to create a user-friendly desktop application (.exe) that allows users to easily transcribe, translate, and summarize spoken content without needing complex installations or external dependencies.



🛠 Key Features
✅ Multilingual Transcription: Supports various languages using Whisper.
✅ Real-Time Speech Recognition: Can process audio from microphone input or pre-recorded files.
✅ Text Summarization: Uses BART to generate concise summaries.
✅ Translation Support: Can translate the transcribed text into multiple languages.
✅ Offline Functionality: The model runs locally without requiring an internet connection.,
✅ Standalone .EXE File: Converts the Python project into a single executable file for easy distribution.



📦 Technologies Used
Whisper (by OpenAI) – For automatic speech recognition (ASR).
BART (by Facebook AI) – For text summarization.
PyTorch – For running deep learning models efficiently.
Pyttsx3 – For text-to-speech conversion.
PyInstaller – To package everything into a single .exe file.
